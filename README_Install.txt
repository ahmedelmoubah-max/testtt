Deutsch Kurs v7 – تصحيح الاستئناف من داخل HTML

1) انسخ index.html و js/app.js و css/style.css إلى مشروعك.
2) مهم جداً: انسخ pages/Kurs/A2/lektion-5-kurs.html إلى نفس المسار داخل المشروع.
3) لا تستبدل مجلد pages كاملاً بالأرشيف؛ احتفظ بالدروس الأخرى الأصلية.
4) افتح الموقع وحدثه Ctrl+Shift+R. تأكد أن ملف درس A2 رقم 5 الجديد هو الذي يُفتح.
5) جرب الدخول إلى المرحلة 3/6 ثم الخروج، وبعدها زر متابعة الدرس.

تخزين التقدم داخل HTML متصل بالطالب الحالي عبر sessionStorage و localStorage.
إذا كان موقعك يخزن التقدم سحابياً في Firebase، ستحتاج قواعد تسمح للطالب بالقراءة والكتابة في عقدة courseProgress الخاصة به.
هذا الملف يتضمن درس A2 Lektion 5 فقط؛ لتطبيق نفس التصحيح داخل بقية دروس HTML يلزم إضافة صفحاتها الأصلية.
